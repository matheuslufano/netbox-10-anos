# Migração para src e nomes locais descritivos

## Resumo das alterações

92 arquivos de aplicação foram movidos para `src`, mantendo as URLs e a separação de responsabilidades. Os 37 CSS Modules usam nomes locais descritivos; referências TSX e composições acompanham a mudança. Elementos estruturais e controles receberam hooks `data-ui`, preservando os tokens existentes.

`src/app` mantém o App Router. Telas completas ficam em `src/components/pages`, pois `src/pages` ativaria o Pages Router. `src/app/layout.tsx` define o HTML base. Fontes importadas ficam em `src/assets/fonts`; imagens e ícones com URLs públicas continuam em `public`.
